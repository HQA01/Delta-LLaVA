# Delta-LLaVA

Official project page for **Decoding the Delta: Unifying Remote Sensing Change Detection and Understanding with Multimodal Large Language Models**, accepted at **ACM Multimedia 2026 (ACM MM 2026)**.

**Authors:** Xiaohe Li, Jiahao Li, Kaixin Zhang, Yuqiang Fang, Leilei Lin, Hong Wang, Haohua Wu, and Zide Fan.

Delta-LLaVA studies unified remote sensing change detection and change understanding with multimodal large language models. The accompanying **Delta-QA** dataset supports multi-temporal remote sensing visual question answering, covering SECOND, LandsatSCD, and WUSU-SCD.

## Resources

- **Paper:** [ACM Digital Library](https://doi.org/10.1145/3767308.3835592) | [arXiv](https://arxiv.org/abs/2604.14044)
- **Dataset (Delta-QA):** Coming soon on Hugging Face

*Note: The Delta-QA dataset will be released publicly. Model code and weights are not provided.*
