# Delta-LLaVA

**Decoding the Delta: Unifying Remote Sensing Change Detection and Understanding with Multimodal Large Language Models**  
*ACM Multimedia 2026*

**Authors:** Xiaohe Li, Jiahao Li, Kaixin Zhang, Yuqiang Fang, Leilei Lin, Hong Wang, Haohua Wu, and Zide Fan.

## Dataset

**Delta-QA** is a visual question answering dataset for multi-temporal remote sensing change detection and understanding. Built upon SECOND, LandsatSCD, and WUSU-SCD, it provides question-answer annotations for bi-temporal and tri-temporal imagery, including spatial prompts and grounding information for applicable tasks.
